# AIR11 Mach 23.9 example fragments

This directory documents the interface configuration used during development. It intentionally excludes the mesh, restart solution, full PATO material case, and all simulation output.

Use these files as configuration references only. They are not a complete executable case.

Key development characteristics included a two-temperature thermochemical nonequilibrium AIR11 flow, a Python-custom wall marker, catalytic-wall treatment, persistent restart-based SU2 state, and a PATO heat-flux wall boundary.
